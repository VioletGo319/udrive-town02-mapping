Overleaf project for Intro2AV Project 2

1. In Overleaf choose New Project > Upload Project and upload the supplied ZIP.
2. Set main.tex as the main document and use pdfLaTeX.
3. Recompile. The supplied technical_report.pdf is compiled from this same source.

Files required for compilation:
  main.tex
  alignment_values.tex
  map_quality_values.tex
  figures/map_evidence.png

Only final_submission_20261023/map.pcd and technical_report.pdf are submission files.
The Overleaf ZIP is editable source; it contains no input bag or teacher map.
If adding group member names, keep the report within one page after recompiling.
